# Olympiad Aggregator

Агрегируем результаты 50+ мероприятий (ВсОШ, Высшая проба, НТО и другие) в удобном UI с подробной статистикой

## Принципы

### Открытость

Мы используем данные, опубликованные публично и официально.
Участники этих мероприятий дали согласие на обработку персональных данных с целью распространения, и мы используем только то, что опубликовали сами организаторы

### Автоматизация и воспроизводимость

Все данные собираются автоматически, уровень ручной работы сведен к минимуму. Пайплайн парсинга и обработки данных находится в [src/data](src/data).

Любой человек может запустить любой шаг пайплайна локально и получить такие же результаты, какие опубликованы на сайте.
Парсинг данных перед деплоем происходит автоматически в GitHub Actions: https://github.com/olympagg/olympagg.github.io/actions/workflows/push.yml

Допущения:

- используем Mistral Document AI для OCR протоколов ВсОШ и других документов
- используем Gemini для нормализации части данных (школы, регионы) при помощи LLM
- запросы к таблицам Innopolis Open при парсинге в CI используют российский прокси

### Идентифицируемость

Любая запись об участии в мероприятии привязана к конкретному человеку и содержит его результат участия (балл, статус, степень диплома)

## Запуск

Мы используем bun: https://bun.com/docs/installation

### Установка зависимостей

```bash
bun install
```

### Сбор данных и preview

Перед запуском приложения нужно собрать данные (получить `eventBundle.json`).

Можно:

- взять готовый файл из артефактов CI: https://github.com/olympagg/olympagg.github.io/actions/workflows/push.yml?query=branch%3Amain -> последний запуск -> скачайте артефакт `event-bundle` -> положите его в `src/data/eventBundle.json`
- запустить `bun parse`: об этом в разделе [Парсинг данных](#парсинг-данных)

После этого запустите локальный сервер:

```bash
bun dev
```

Приложение будет доступно на http://localhost:3000

## Парсинг данных

`bun parse` запускает все сборщики: скачивает исходные протоколы (HTML/PDF/XLSX),
парсит их в типизированный JSON в `src/data/parsed/` и собирает итоговый
`src/data/eventBundle.json`, который использует фронтенд.

Для парсинга нужны секреты в `.env` (шаблон — в [`.env.example`](.env.example)):

- `MISTRAL_API_KEY` — Mistral Document AI, OCR протоколов ВсОШ и других PDF;
- `GEMINI_API_KEY` — Gemini, нормализация школ и регионов через LLM;
- `PROXY_URL` / `PROXY_DOMAINS` — прокси через российский IP для источников,
  блокирующих зарубежные адреса (например, таблицы Innopolis Open).

```bash
bun parse
```

Скачанные исходники кешируются в `src/data/cache/` (в git не попадает), поэтому
повторный запуск работает быстрее.
